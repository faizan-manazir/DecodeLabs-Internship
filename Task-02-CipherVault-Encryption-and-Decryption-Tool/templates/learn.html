LEARN CRYPTOGRAPHY

Understand before you encrypt.

Use the workspace's How It Works tab for an algorithm-specific explanation, process steps, key type, and example.

Classical

Caesar, Vigenère, Atbash, and Rail Fence demonstrate historical substitution and transposition concepts. They are not suitable for modern sensitive data.

Key-Based

XOR demonstrates reversible byte-level transformation. Security depends heavily on key construction and reuse; the repeating-key implementation is educational.

Modern

Fernet and AES-GCM provide authenticated encryption using established cryptographic primitives. This application derives keys from passwords and packages fresh salts/nonces with ciphertext.

Important: Encoding vs Encryption

Base64 is intentionally not included as a CipherVault technique because it is encoding, not encryption. It changes the representation of bytes so they can be transported as text, but anyone can decode it and it provides no secrecy.

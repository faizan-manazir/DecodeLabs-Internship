    Key takeaways
    • Classical ciphers are useful for learning but not modern protection.
    • Base64 is not included as a technique because it is encoding, not encryption. It changes representation but does not hide information or require a secret.
    • Repeating-key XOR is reversible but this implementation is educational.
    • Fernet and AES-GCM provide authenticated encryption when used correctly.
    • Password strength and key management remain critical to practical security.
